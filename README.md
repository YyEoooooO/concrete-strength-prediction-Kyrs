# Прогнозирование прочности бетона с оптимизацией MLP генетическим алгоритмом

## 1. Цель проекта

Разработать программную систему прогнозирования прочности бетона на сжатие
по его составу и условиям формирования. В рамках проекта необходимо:

- выполнить предварительную обработку данных;
- реализовать многослойный персептрон (MLP) на Python и NumPy;
- реализовать генетический алгоритм (ГА) для оптимизации параметров сети;
- сравнить обучение градиентными методами и генетическим алгоритмом;
- провести серию экспериментов с параметрами ГА и проанализировать
  эффективность эволюционной оптимизации.

**Тип задачи:** регрессия (прогнозирование числового значения прочности).

## 3. Метрики качества

Для оценки регрессионной модели используются:

| Метрика | Формула / смысл | Направление |
|---|---|---|
| **RMSE** (Root Mean Squared Error) | `sqrt(mean((y_true - y_pred)^2))` | меньше — лучше |
| **MAE** (Mean Absolute Error) | `mean(|y_true - y_pred|)` | меньше — лучше |
| **R²** (коэффициент детерминации) | `1 - SS_res / SS_tot` | ближе к 1 — лучше |
| **Время обучения** | wall-clock time, сек | справочно |

Основная метрика для выбора модели — **RMSE на валидационной выборке**.
Финальная оценка — на тестовой выборке.

## 4. Требования к воспроизводимости

- **Фиксированный random seed** для всех этапов: разбиение данных,
  инициализация весов, генерация популяции ГА, перемешивание батчей.
- **Сохранение конфигураций экспериментов** в JSON/YAML вместе с результатами.
- **Фиксация версий библиотек** в `requirements.txt`.
- **Запуск с одним и тем же seed должен давать идентичные результаты**
  (в пределах детерминизма используемых операций).
- Рекомендуется сохранять:
  - параметры нормализации (mean/std или min/max);
  - индексы train/val/test;
  - лучшие веса модели;
  - логи обучения и метрики по эпохам/поколениям.
